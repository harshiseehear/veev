# Veev React App

A modern React web application built with Vite.

## Getting Started

### Prerequisites
- Node.js (v14 or later)
- npm or yarn

### Installation

Install dependencies:
```bash
npm install
```

### Development

Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

Build for production:
```bash
npm run build
```

### Preview

Preview the production build:
```bash
npm run preview
```

## Project Structure

```
veev/

│   ├── App.css       # App styles
│   ├── main.jsx      # Entry point
```

## Technologies

- **React 18** - UI library
- **Vite** - Build tool and dev server
